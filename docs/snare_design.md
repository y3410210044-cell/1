# くくり罠 自動作動の設計 — 「AIで撃つ」から「AIで解錠する」へ

## 1. 課題: くくり罠はミリ秒の世界

歩行中のイノシシの足が踏板に載っている時間は **0.3〜0.6秒**。
電子トリガー(カメラ→AI→SwitchBot)の総遅延は最良で約1.3秒、クラウド経由なら5秒。
**「足を置いた瞬間に電子的に作動させる」ことは物理的に不可能。**

| 経路 | 遅延の目安 |
|---|---|
| カメラ1フレーム (15fps) | ~70ms |
| YOLOv8n 推論 (Pi 4 CPU / NCNN) | 150〜400ms |
| GPIO→ソレノイド | **5〜20ms** ← 唯一速い経路 |
| SwitchBot BLE(接続+押下) | 1000〜3000ms |
| SwitchBot クラウドAPI(+押下) | 2000〜5000ms |

## 2. 3つのアーキテクチャ比較

### 案A(推奨): AIインターロック方式 — 機械式トリガー + 電磁ロック
- 踏板→バネの**純機械トリガーは残す**(遅延ゼロ)。
- 踏板 or シア(蹴糸金具)にソレノイドピンを噛ませて常時**物理ロック**。
- AIが「対象=イノシシ/シカ、禁止対象なし、接近中」を確認した間だけ**通電解錠**。
- AIに必要な応答速度: 獣が罠に到達するまでの数秒〜数十秒 → **余裕で間に合う**。
- 停電・SW障害・電池切れ → 消磁=ロック → **誤作動側に倒れない(フェイルセーフ)**。
- 副次効果: カモシカ・イヌ・人・子グマでは構造的に発火しない。
  **錯誤捕獲防止はくくり罠の最大の実務課題であり、これが本方式の最大の価値。**

### 案B: 電子直接発火方式 — 餌で静止させて撃つ
- 踏板を使わず、ソレノイド/サーボで直接シアを解放。
- 餌を発火点の真上に置き、イノシシが**採食で静止**(数秒〜数十秒)する状況を作る。
- 「足先(=バウンディングボックス下端中央)が発火ゾーンに N フレーム連続滞在」で発火。
- 遅延許容は静止時間に依存。歩行通過には効かない。設置(餌の位置)が精度を決める。

### 案C: SwitchBot で直接作動(不採用)
- Bot のアーム動作+通信で 1.5〜5秒。くくり罠では取り逃し確定。
- → SwitchBot は「遠隔での再ロック/解錠切替」「捕獲後の通知確認」用途に回す。
  (囲い罠・箱罠のゲート落としには引き続き有効。)

## 3. ハードウェア構成(案A)

```
[電源] 12Vバッテリ(+ソーラー)
   ├─ DC-DC 5V → Raspberry Pi (Zero 2 W / 4)
   ├─ [MOSFETドライバ/リレー] ←GPIO← Pi
   │        └─ 12V プッシュプル・ソレノイド(引きバネ内蔵, 通電で引込=解錠)
   ├─ USB/CSI カメラ(赤外線対応, 夜間は IR 投光器)
   └─ PIR センサ(任意: 動体でカメラ&AIをwake, 待機電力削減)

機構: ソレノイドのピンが踏板の沈み込み(またはシアの回転)を物理的に阻止。
      通電するとピンが引っ込み、踏板が沈める=発火可能になる。
      ※ばね押し出し・通電引込の「ノーマリーロック」型を選ぶこと。
```

部品目安: ソレノイド ¥800〜2,000 / MOSFETモジュール ¥300 / Pi Zero 2 W ¥3,000〜。

## 4. 制御ロジック(実装: `snare_trap.py`)

```
LOCKED ──(イノシシ/シカ確認 & 禁止対象なし & 接近ゾーン内)──→ UNLOCKED(通電)
UNLOCKED ──(対象がいなくなる / 禁止対象出現 / タイムアウト)──→ LOCKED(消磁)
UNLOCKED ──(踏板発火を検知: 振動センサ or 画像変化)──→ FIRED → 通報・以後ロック維持
```

- 解錠は「対象が見えている間+猶予数秒」だけ。ゾーンから出たら即再ロック。
- **禁止クラス(人・クマ・イヌ・カモシカ)が1体でも見えたら、対象がいても即ロック。**
- 案B(direct)モードでは、足先が発火ゾーンに `dwell_frames` 連続で入った時に GPIO 発火。

## 5. 法令・運用の注意(必読)

- くくり罠は輪の直径(多くの県で12cm以下)、締付防止金具、よりもどし等の**構造規制**が
  都道府県ごとにある。**電動ロック機構の追加が構造規制に抵触しないか、必ず県担当課に確認**すること。
- 狩猟免許(わな猟)と登録/許可が前提。
- 捕獲後は速やかな見回り・処置が法令(動物愛護)上も必要。**通知機能は必ず有効にする。**
- カモシカ錯誤捕獲は文化財保護法にも関わる。禁止クラスの学習データを疎かにしないこと。
